# SpeedFlow Web

Official landing page and website for **SpeedFlow** — High-Performance Minimalist Desktop Download Manager & Network Accelerator.

Built with **Astro v5**, **Zero Database (100% Static)**, and **Strict Flat UI Design Language**.

## Features

- **Strict Flat Minimalist Design**: Clean hairline borders, 2px radius, and tokens matching native desktop Slint UI.
- **Physical Monitor Device Simulator**: Auto-cycling screenshot showcase of the SpeedFlow native Windows desktop client.
- **Zero Database Architecture**: 100% static client-side generation for instant load times and zero server maintenance.
- **Benchmark & Comparison Matrix**: Transparent comparison between SpeedFlow, IDM, Gopeed, and default browsers.
- **Interactive FAQ Accordion**: Clear, human-friendly answers to common questions about multi-thread downloads and security.
- **Direct WebExtension Downloads**: Packaged extensions for Microsoft Edge, Mozilla Firefox, and Chromium.

## Getting Started

### Prerequisites

- Node.js (v18.17.1 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Kharisdestianmaulana-hub/speedflowweb.git
cd speedflowweb

# Install dependencies
npm install
```

### Development

```bash
# Start local development server (port 4321)
npm run dev
```

### Production Build

```bash
# Build static production bundle into dist/
npm run build

# Preview production build locally
npm run preview
```
